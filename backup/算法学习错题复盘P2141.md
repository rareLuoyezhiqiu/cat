## [原题链接](https://www.luogu.com.cn/problem/P2141)
最开始想到了主思想暴力枚举，因为n的范围在3到100，很小可以支撑暴力枚举的时间复杂度，但误解了题意，误认为是统计总方案数而不是符合原题的数字数量，于是直接使用i，k用不降原则直接遍历了整个数组，很显然3AC7WA。之后发现需要的是判断符合条件数字的数量，于是上一种思路中最大的问题是重复计数，1+4=5,2+3=5，但其实只算num+1，于是引入了状态数组bool b[n]，如果all=这个数并且这个数以前没被计数过才num+1，并且把这个数的bool状态改成已计数过，下次自然不再计数。题解思路于此，错因偏向审题不清楚，另外bool判断状态这个思路也可以学习一下
```c++
#include<bits/stdc++.h>
using namespace std;
int main(void)
{int n,num=0;
 cin>>n;
 vector<int> a(n);
 bool b[n];
 for(auto &i : b)i=false;
 for(int i=0;i<n;i++)cin>>a[i];
 for(int i=0;i<n;i++)
 for(int k=i+1;k<n;k++)
 {int all=a[k]+a[i];
  for(int j=0;j<n;j++)
  {if(all==a[j]&&b[j]==false){num++;b[j]=true;};};};
 cout<<num;
 return 0;
}
```
