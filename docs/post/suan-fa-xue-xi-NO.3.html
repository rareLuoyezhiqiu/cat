T839151 抠门的管理员

题目描述
管理员准备给 n 位干员发奖金。每位干员在左手和右手各写一个整数，管理员自己也在左右手各写一个整数。n 位干员排成一排，管理员站最前。每位干员获得的奖金为：排在该干员前面的所有人（包括管理员）左手上的数的乘积，除以该干员自己右手上的数，向下取整。管理员希望重新安排队伍顺序，使得获得奖金最多的干员所获奖金尽可能少。注意管理员位置始终在队伍最前面。
输入格式
第一行一个整数 n。第二行两个整数 a,b，表示管理员左手和右手上的整数。接下来 n 行每行两个整数 a,b，表示每位干员左手和右手上的整数。
输出格式
一个整数，表示重新排列后的队伍中获得奖金最多的干员所获得的奖金数。
数据范围
对于 60% 数据，1 <= n <= 8；对于 100% 数据，1 <= n <= 30，0 < a,b < 10000，保证答案不超过 10^9。

#include <bits/stdc++.h>
using namespace std;
typedef long long ll;//等价于define

struct Person {
    ll l, r;
    bool operator<(const Person &o) const {//这是什么诡异语法
        return l * r < o.l * o.r;
    }//理论上应该是从小到大排序
};
int main() {
    int n;
    cin >> n;
    ll a, b;
    cin >> a >> b;
    vector<Person> p(n);//建立一个内部元素为person的名叫p的数组
    for (int i = 0; i < n; i++)
        cin >> p[i].l >> p[i].r;
    sort(p.begin(), p.end());//如果不出意外的话服从比较器应该是person里面的boolreturn从小到大的比较

    ll prod = a, ans = 0;
    for (int i = 0; i < n; i++) {
        ans = max(ans, prod / p[i].r);//ans找目前出现过的最大值,注意这里的prod除以right才是这个人应该得到的奖金数
        prod *= p[i].l;//奖池累计说是,prod每乘一个人的left就增加一次,但注意这里prod不是这个人得到的奖金数
        if (prod > (ll)1e18) prod = (ll)1e18; // 防溢出//所以貌似根据题目所给的条件这一行其实可以去掉(?)
    }                                                           //不过还是写一下吧，这里意思应该是把大于10的18次方的prod强行赋值成10的18次方
    cout << ans << endl;
    return 0;
}

题解答案居然不是暴力枚举每一种情况比较最大值，当时想到的唯一办法就是把全部方案都暴力枚举出来计算（不过也没啥用，我忘了暴力枚举怎么暴力了（）），解法核心思想贪心策略，局部最优也是全局最优解，我草我真没想到这个，升序排序就是最优解我草
